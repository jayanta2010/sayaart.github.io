Return & Replacement Policy

Customers may submit a return or replacement request from their account using the 10-digit order ID and at least 3 clear photos showing the item and the issue. A request is not automatically approved when submitted.

After submission, the store team reviews the request. The expected review time is within 36 working hours. Approval, rejection, or a request for more information will be shown against the return request when updated by the store team.
